# Emberfall Vault

A complete one-room Zelda-style dungeon built with plain HTML, CSS, and Canvas 2D. No frameworks, no build step, no runtime dependencies.

- **Objective:** find the Ember Key in the reliquary, break the seal, and defeat Morgrave, the Cinder Warden.
- **The fight:** three phases with slam shockwaves, charges, fire volleys, fissures, and summoned embers.
- **Controls (desktop):** `WASD`/arrows move, `J` slash, `Space`/`Shift` dodge, `E` interact, `M` mute.
- **Controls (touch):** virtual stick on the left; slash, dodge, and use buttons on the right.
- **Presentation:** procedural art and audio, torch-lit stone chamber, responsive layout for phone, tablet, and desktop.

Run `./start.sh` (or serve the folder with any static server) and open `index.html`. Add `?debug` to expose the `window.__emberfall` test hooks.

All art, fonts, and audio are bundled locally. Fonts: Cinzel and Spectral (SIL Open Font License).
